本文件中心提供以正體中文撰寫的使用手冊、教學、測試與部署流程。

## 文件導覽

## 建議閱讀順序

1. 先閱讀「快速開始教學」完成第一張圖片與第一批資料。
2. 依照「預設參數建議」挑選 `tw_readable / tw_balanced / tw_aggressive / tw_hardened`。
3. 上線前請跑「測試與部署指南」中的完整測試與部署 smoke。
4. 若要規劃後續迭代，參考 Roadmap 文件。
